🔧 Fix TNI Bot Session

AuthKeyDuplicatedError — Tự sửa theo từng bước
⚠ Nguyên nhân lỗi AuthKeyDuplicatedError: Session file Telethon đang dùng ở 2 nơi cùng lúc (máy local + GitHub Actions). Phải tạo lại session string mới.
💻CMD
🗑Xóa Session
🔑Tạo Mới
🐙GitHub
✅Xong
1Mở CMD — Vào thư mục bot
⚠ Tắt hết script đang chạy local trước!
📁 Di chuyển vào thư mục project
cd /d "d:\6. AI\1. QLTC\Task and WO"
🐍 Kích hoạt venv (nếu dùng virtual env)
venv\Scripts\activate
2Xóa session file cũ bị conflict
🗑 Xóa toàn bộ file .session
del *.session
🔍 Kiểm tra đã xóa hết chưa
dir *.session
3Tạo Session String mới (Telethon)
💡 Nhập SĐT Telegram → nhận mã OTP → copy chuỗi SESSION dài in ra
▶ Chạy script tạo session (nếu có file generate_session.py)
python generate_session.py
▶ Hoặc chạy nhanh inline (không cần file)
python -c "from telethon.sync import TelegramClient; from telethon.sessions import StringSession; api_id=int(input('API_ID: ')); api_hash=input('API_HASH: '); c=TelegramClient(StringSession(),api_id,api_hash); c.start(); print('\n=== SESSION STRING ===\n', c.session.save()); c.disconnect()"
✅ Copy chuỗi dài bắt đầu sau "SESSION STRING" để dùng ở bước 4
4Cập nhật GitHub Secrets

→ Mở github.com/phonghdpxd-cmd/tni-bot

→ Nhấn Settings → Secrets and variables → Actions

→ Tìm secret tên SESSION_STRING → nhấn ✏ Update

→ Paste chuỗi session mới vào → Save secret

→ Vào tab Actions → chọn workflow bị lỗi → nhấn Re-run failed jobs

⚡Phòng ngừa tái phát
⚠ KHÔNG chạy cùng session Telethon trên máy local trong khi GitHub Actions đang chạy! Một session = một nơi duy nhất.

Nếu cần debug local → tạo session riêng cho máy local, session riêng cho GitHub.
